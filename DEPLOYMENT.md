## Aiven Database Setup

### Create Aiven Account
1. Visit https://aiven.io
2. Sign up for a free account
3. Verify your email address

### Create MySQL Service

1. **Click "Create Service"**
2. **Select MySQL**
   - Version: MySQL 8.0
3. **Choose Plan**
   - Select "Startup" (free tier)
   - 1 node, 1GB RAM
4. **Select Region**
   - Choose closest to your Render deployment region
   - Recommended: US East or EU West
5. **Name Your Service**
   - Example: `gps-tracking-db`
6. **Click "Create Service"**
7. **Wait 2-3 minutes** for service to initialize

### Get Connection Details

Once service is running:

1. Navigate to **Overview** tab
2. Copy the following information:
   ```
   Host: mysql-xxxxx.aivencloud.com
   Port: 12345
   User: avnadmin
   Password: [your-generated-password]
   Database: defaultdb
   ```
3. Save these for later use

### Import Database Schema

**Option A: Automatic (Recommended)**
- The Node.js server automatically creates tables on first run
- No manual setup needed

**Option B: Manual Setup**
1. Go to Aiven Console → **SQL Editor** tab
2. Open `database/aiven-schema.sql` from this repository
3. Copy the contents
4. Paste into SQL Editor
5. Click "Execute"
6. Verify tables created:
   ```sql
   SHOW TABLES;
   ```

### Verify Database Connection

Test connection from SQL Editor:
```sql
SELECT * FROM gps_devices;
SELECT * FROM gps_data;
```

## Render Deployment

### Prerequisites
- GitHub account
- Code pushed to GitHub repository
- Aiven database credentials ready

### Push Code to GitHub

If not already done:
```bash
cd webServGPS-clean
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/yourusername/gps-webservice.git
git push -u origin main
```

### Create Render Account

1. Visit https://render.com
2. Click "Get Started for Free"
3. Sign up with GitHub
4. Authorize Render to access your repositories

### Create Web Service

1. **Click "New +"** → **Web Service**
2. **Connect Repository**
   - Find your `gps-webservice` repository
   - Click "Connect"
3. **Configure Service**
   - **Name:** `gps-webservice` (or your preferred name)
   - **Region:** Same as Aiven (US East or EU West)
   - **Branch:** `main`
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
4. **Select Plan**
   - Choose "Free" tier

### Set Environment Variables

Before deploying, add environment variables:

1. Scroll to **Environment** section
2. Click "Add Environment Variable"
3. Add the following (use your Aiven credentials):

```
DB_HOST=mysql-xxxxx.aivencloud.com
DB_USER=avnadmin
DB_PASS=your-aiven-password
DB_NAME=defaultdb
DB_PORT=12345
PORT=10000
```

> **Important:** Double-check all values are correct!

### Deploy

1. Click **"Create Web Service"**
2. Wait for build and deployment (3-5 minutes)
3. Monitor logs for:
   ```
   GPS WebService Starting...
   Checking database tables...
   Database tables verified/created
   Server running on port 10000
   ```
4. Note your service URL: `https://gps-webservice.onrender.com`

## Common Issues

### Issue: "Database connection failed"

**Symptoms:**
- API returns 500 error
- Logs show connection timeout

**Solutions:**
1. Verify environment variables are correct
2. Check Aiven service is running (not paused)
3. Ensure SSL is enabled in connection config
4. Test connection from Aiven SQL Editor
5. Check firewall settings

**Debug:**
```bash
# Check Render logs
render logs -f

# Look for this line
DB Connection established
```

### Issue: "Tables don't exist"

**Symptoms:**
- Error: "Table 'gps_devices' doesn't exist"

**Solutions:**
1. Restart Render service (re-deploys)
2. Manually create tables from SQL Editor
3. Check logs for table creation errors

**Fix:**
Run `database/aiven-schema.sql` in Aiven SQL Editor

### Issue: "Service won't start"

**Symptoms:**
- Render shows "Deploy failed"
- Build errors in logs

**Solutions:**
1. Check `package.json` has correct dependencies
2. Verify Node.js version (>=16.0.0)
3. Check build command: `npm install`
4. Check start command: `npm start`

**Debug:**
Review build logs in Render dashboard

### Issue: "ESP32 can't connect"

**Symptoms:**
- ESP32 shows HTTP error
- Serial Monitor: "Connection failed"

**Solutions:**
1. Verify Render URL is correct (include `https://`)
2. Check server is running (visit health endpoint)
3. Ensure `client->setInsecure()` is called
4. Check WiFi connection on ESP32

**Test:**
```cpp
const char* serverName = "https://your-service.onrender.com/api/gps/push";
```

### Issue: "Render service sleeps"

**Symptoms:**
- First request takes 30+ seconds
- Service inactive during night

**Explanation:**
- Free tier services sleep after 15 minutes of inactivity
- First request "wakes up" the service

**Solutions:**
1. Use paid plan for 24/7 uptime
2. Set up ping service (e.g., UptimeRobot)
3. ESP32 will automatically retry after timeout

### Issue: "Too many connections"

**Symptoms:**
- Error: "Too many connections"
- Random connection failures

**Solutions:**
1. Check connection pool limit (default: 10)
2. Increase `connectionLimit` in `index.js`
3. Upgrade Aiven plan for more connections

**Fix:**
```javascript
const pool = mysql.createPool({
  connectionLimit: 20, // Increase if needed
  ...
});
```

## Updating Deployment

### Deploy New Changes

1. Push changes to GitHub:
   ```bash
   git add .
   git commit -m "Your changes"
   git push
   ```

2. Render automatically redeploys
3. Monitor deployment in Render dashboard
4. Check logs for errors

### Manual Deploy

1. Go to Render dashboard
2. Select your service
3. Click "Manual Deploy" → "Deploy latest commit"

### Rollback

If deployment fails:
1. Go to Render dashboard
2. Click "Events" tab
3. Find last successful deploy
4. Click "Rollback to this version"

- ✅ HTTPS only (HTTP disabled)
- ✅ SSL database connections
- ✅ Parameterized SQL queries (prevents injection)
- ✅ Input validation on all endpoints
